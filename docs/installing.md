# Install Time Loop

On supported desktop or Android browsers, open **Settings → Install game**. You can also use your browser's install option in its address bar or menu.

On iPhone or iPad, open the game in Safari, tap **Share → Add to Home Screen → Add**. **Settings → Install game** shows these instructions.

Open the installed app from your home screen or app launcher. It uses the same saved game as that browser. After the first successful online visit finishes downloading the game, it can reopen offline. Clearing browser/site data also clears saves and offline files.

The Last Market Day starts a new campaign and stores it separately from the original Time Loop game. The old game’s save stays on this device. The original source is preserved under the `pre-redesign` tag.

Updates download when online and take over after all windows/tabs of that installation close. This avoids replacing the game while you are playing. Reopen it to use the downloaded update.

PR previews install separately, with their own scope, offline cache, and existing preview save. Their URLs are temporary; use the main site for a permanent installation.
